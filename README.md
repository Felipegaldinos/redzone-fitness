# RedZone Fitness

Landing page estática para apresentação de academia.

## Recursos

Seções de apresentação, planos, depoimentos e chamada para aula experimental.

## Tecnologias

HTML, CSS e JavaScript; sem etapa de build npm na estrutura analisada.

## Executar localmente

Sirva os arquivos por HTTP; uma opção com Python 3 instalado:

```sh
git clone https://github.com/Felipegaldinos/redzone-fitness.git
cd redzone-fitness
python -m http.server 8000
```

Abra http://localhost:8000. Recursos de terceiros, quando usados, exigem conexão com a internet.

## Onde começar no código

- `index.html` — ponto de entrada para entender o projeto.

## Estado atual

Revise dados demonstrativos e confirme o destino das chamadas de atendimento; a presença de planos na página não implementa cobrança.
